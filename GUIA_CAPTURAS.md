# Guía de capturas — MobileConnect

1. **Interfaz:** app abierta con A/B, campo y lista vacía o con mensajes.
2. **Mensajes desde A y B:** envía al menos uno como A y otro como B (burbujas de distinto color + hora).
3. **Validación vacíos:** campo vacío o solo espacios → Enviar → snackbar “No se puede enviar un mensaje vacío”.
4. Opcional: contadores “Enviados” y botón limpiar historial.

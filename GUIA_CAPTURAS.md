# Guía de capturas — MobileConnect

## Teléfono propio (1–4)
1. Chat conectado como B con mensajes A/B.
2. Historial con contadores Msgs A / Msgs B.
3. Error de red (`Socket closed`) — evidencia de canal real.
4. Validación / snackbar al intentar enviar sin estado válido.

## Teléfono de la pareja (5–8)
5. Pantalla Conectar (IP, puerto, sala).
6. Conectado sin rol aún.
7. Primer intercambio «hola».
8. Chat completo (identidades / contadores).

## Código (9)
9. Switch `codigoWire` / `fromCodigoWire` para roles A y B.
